# Elas por Aí 🌸

> Plataforma e comunidade feminina voltada para a conexão de mulheres, fortalecimento de laços, criação de memórias e divulgação de eventos exclusivos.

---

## 🎨 Sobre o Projeto

O **Elas por Aí** é uma aplicação web moderna desenvolvida para aproximar mulheres através de encontros presenciais e dinâmicas online. A plataforma conta com uma interface acolhedora, vibrante e responsiva, inspirada em grandes portais de comunidade, contendo seções dinâmicas como agenda de eventos, apresentação de idealizadoras e galeria estilo mosaico.

---

## 🚀 Tecnologias Utilizadas

Este projeto foi construído utilizando as tecnologias mais modernas do ecossistema web:

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Estilização:** [Tailwind CSS v4](https://tailwindcss.com/) (com configuração de tema customizado via `@theme`)
- **Ícones:** [Lucide React](https://lucide.dev/) & [React Icons](https://react-icons.github.io/react-icons/)
- **Linguagem:** TypeScript
- **Deploy & Hospedagem:** Vercel (`site.elasporai.com`)

---

## 🌟 Principais Seções da Landing Page

- **Hero Section:** Mosaico fotográfico responsivo com efeito de zoom suave e carrossel adaptado para dispositivos móveis.
- **Sobre a Comunidade:** Manifesto e proposta de valor acolhedora para as usuárias.
- **Agenda de Eventos:** Cards interativos contendo data, horário, localização, categorias (Presencial/Online) e link direto para vagas.
- **Idealizadoras:** Seção dedicada às co-fundadoras do projeto com mini bios e redes sociais.
- **CTA & Rodapé:** Seção de chamada para entrada no grupo oficial e links de navegação rápida.

## 🛠️ Como Executar o Projeto Localmente

Siga os passos abaixo para rodar o projeto na sua máquina:

```bash
# 1. Clone o repositório
git clone [https://github.com/elasporai/elas-por-ai.git](https://github.com/elasporai/elas-por-ai.git)

# 2. Acesse a pasta do projeto
cd elas-por-ai

# 3. Instale as dependências
npm install

# 4. Inicie o servidor de desenvolvimento
npm run dev
```
